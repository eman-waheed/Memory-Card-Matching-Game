Memory Card Matching Game

Overview
A Python-based memory game developed with Tkinter. 
Players flip two cards at a time and try to find matching pairs. 
The project demonstrates GUI programming and simple AI-driven logic.

Features
- Interactive GUI built with Tkinter
- Random card shuffling for replayability
- Tracks moves and game completion time
- Displays matched pairs visually

Tech Stack
- Language: Python
- Libraries: Tkinter, random, time
